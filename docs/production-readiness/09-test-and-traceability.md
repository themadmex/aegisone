# Test strategy and traceability

**Evidence status.** All runtime tests below are NOT VERIFIED. There is no implementation to execute. The evidence column names the future CI artifact or restricted staging record. Attach exact release, environment, command or steps, timestamp, expected and observed results, and redacted outputs. Preserve approved runs in the release record. Use representative synthetic tenants and an owned DNS fixture zone.

| Test | Requirements | Environment and passing behavior | Evidence / owner |
|---|---|---|---|
| V01 Identity and roles | FR-01, NFR-01 | CI PostgreSQL integration and staging E2E. Concurrent invite redemption accepts one, recovery invalidates sessions, MFA blocks bypass, and former members lose access on the next request | Identity CI trace / Engineering |
| V02 Assessment | FR-02, FR-03 | Unit score rounding/unsure fixtures. Integration concurrency/replay yields one immutable snapshot and consistent dashboard. Mobile and desktop E2E resume last saved answer and handle network retry | Assessment CI + browser recording / Engineering |
| V03 Actions | FR-04 | Unit catalog rule and ordering fixtures. Integration tests legal transitions, unauthorized roles, stale writes, duplicate records and same-gap recurrence with retained history | Action CI / Product + Engineering |
| V04 DNS proof and checks | FR-05, NFR-01, NFR-07 | Synthetic resolver plus project-operated zone. Reject missing, expired or revoked proof, wrong role and blocked scope. Bound queries, job attempts and concurrency, and publish no stale result when a lease or authorization is lost. Test ambiguous/missing records and resolver outage | Worker CI + staging logs / Security |
| V05 Reports | FR-06, NFR-05 | Integration and E2E. Stable timestamped snapshot despite later changes, no cross-tenant or public access, no-store headers, revocation, release-compatible rendering and usable print preview | Report CI + print review / Engineering |
| V06 Rights and retention | FR-07, NFR-05 | Staging. Validate identity and scope, export only intended records, revoke closing tenant access, enforce expiry/purge and capture deletion replay with restored data | Privacy review and drill / Privacy + Platform |
| V07 Clean install and supply chain | FR-08, NFR-06 | Clean independent host, verified build inputs and upgrade, dependency/license/secret scans, SBOM and provenance. Scan repo/history, configuration, logs, production asset manifests and maps for exposure | Install log and release artifacts / Release |
| V08 Object and row authorization | NFR-01, FR-01–07 | CI and staging. Exercise protected requests directly with synthetic unrelated tenants, altered roles, IDs and revisions. Check forged state and replay rejection. Verify RLS against runtime roles, unset and reused scope, membership bootstrap, queue, reports and exports | Authorization matrix, DB test log / Security |
| V09 Inclusive experience | NFR-02 | Browser automation plus manual keyboard, VoiceOver or NVDA, TalkBack, zoom, contrast/forced colors and reduced-motion checks. Verify responsive feedback and focus with pointer, touch and keyboard | Accessibility report and recordings / UX |
| V10 Performance and capacity | NFR-03, NFR-07 | Repeatable network/CPU-throttled browser tests and stage load. Meet TRD budgets, isolate noisy workspaces and maintain bounded query counts and spend | Latency and capacity report / Platform |
| V11 Resilience and recovery | NFR-04, NFR-06 | Bounded synthetic drills. Lose mail or DNS, expire leases, restart worker, test migration rollback, restore to isolation, replay deletion and meet RTO/RPO | Drill record with timings / Platform |
| V12 Ops and trust | FR-07, FR-08, NFR-04–07 | Verify notices/routes and real cookie inventory. Redact synthetic sensitive data, exercise alert delivery and rollback flag, verify budget alarm and test monthly SLI queries | Release runbook and policy review / Privacy + Platform |

V01 and V04–V12 contain mandatory high-risk checks. FR-02 through FR-04 are also critical user journeys. Close critical failures and review all outstanding High findings before launch. Use the [OWASP ASVS 5.0.0](https://asvs.owasp.org/) as a verification catalog, the [NIST Cybersecurity Framework](https://www.nist.gov/cyberframework) to guide assessment coverage, and [WCAG 2.2](https://www.w3.org/TR/WCAG22/) for accessibility. Record control mappings and deviations in the eventual evidence; no certification is claimed.
