# Website trust and jurisdiction

Assume the first hosted pilot targets Nigerian businesses. Review operator/controller/processor roles and actual processing with qualified local counsel before live onboarding. The Nigeria Data Protection Act and NDPC implementation directive inform the review, including processing basis, security, transfers, rights, and whether registration, notices, assessment or other obligations apply. Hosting region, actual processors and international expansion remain open. Source review dated 17 November 2026. [Nigeria Data Protection Act 2023](https://ndpc.gov.ng/wp-content/uploads/2024/03/Nigeria_Data_Protection_Act_2023.pdf) · [NDPC General Application and Implementation Directive](https://ndpc.gov.ng/wp-content/uploads/2025/07/NDP-ACT-GAID-2025-MARCH-20TH.pdf)
