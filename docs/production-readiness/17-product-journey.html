AegisOne pilot journey

Start with an invitation, save a security baseline and record the actions your workspace takes. Open each step for its outcome and recovery path.

  1. Accept the invitation and enroll MFA

    Use the invited email, choose a password and verify the authenticator code. Store the recovery codes privately. An expired invitation needs a replacement.

  2. Complete the assessment

    Choose Yes, Partly, No or Unsure for each question. Resume the draft from any signed-in device. Submit after reviewing all 20 answers.

  3. Work through prioritized actions

    Read why each gap appeared, how to address it and how to verify the fix. Change the status and review its activity history.

  4. Save and print a report

    Review the current evidence and save a dated private snapshot. Print a local copy. A newer assessment leaves the saved snapshot intact.

  5. Verify a domain when DNS checks are enabled

    An owner attests authorization, publishes the exact TXT proof and requests verification. A verified name can be checked for SPF and DMARC. Use the detail page to see the result or try again.

  6. Manage access and workspace data

    Use Profile settings for your name or password. Owners can manage workspace membership and request an export or closure. An operator verifies authority before processing.
