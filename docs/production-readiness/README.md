# AegisOne Open first-release planning pack

**17 November 2026 · Draft for founder review**

AegisOne Open helps SME owners assess basic security practices, decide what to fix, record progress, review public email-security DNS records for a verified domain, and produce a management report. The proposal starts with an invite-only Nigerian pilot and a self-hostable open-source distribution for broader reuse.
